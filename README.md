# 医院管理系统 Hospital Management System
C语言控制台课程设计项目。

## 项目简介
本项目为C语言实现的控制台医院管理系统，包含挂号接诊、医生开处方、药品管理、住院床位管理等业务模块。
已完成：患者挂号、接诊、处方开具、药品管理、科室、医生、就诊记录管理。
## 模块清单
- patient：患者信息管理
- doctor：医生信息管理
- bed：住院床位管理
- medicine：药品管理
- prescription：处方开药
- registration：挂号接诊
- department：科室管理
- record：就诊记录
- log：系统日志
- print_utils：打印工具函数
- common.h：全局通用定义

## 编译运行
GCC或C语言编译器编译全部.c源代码，程序通过txt文件持久化保存数据。
